# IJX Platform 客户端设计规范

版本：1.2  
适用范围：`/pc_client` 下的客户端页面
设计基线：消息、日历设计稿与品牌配色规范

## 1. 设计原则

- 整体气质为轻量、克制、清晰的企业协同工具，不使用营销页式的大标题、装饰卡片和强烈阴影。
- 页面由“底面背景”和“白色工作面”构成。底面背景必须在工作面四周和分栏间隙可见，不能被整页白底完全覆盖。
- 页面结构优先表达工作关系：导航、列表、内容区各自独立，避免卡片套卡片。
- 同类页面使用相同分栏、圆角、边框和滚动规则，不在页面内重新定义另一套视觉体系。

## 3. 页面骨架

### 3.1 底面与工作面

- 客户端视口四周保留 `8px` 底面背景。
- 同级工作面之间保持 `8px` 间距。
- 一级工作面圆角统一为 `16px`，边框为白色半透明或 `#E4E7ED` 弱边框。
- 工作面阴影只用于轻微区分层级，推荐 `0 1px 3px rgba(48,49,51,.06)`。
- 一级工作面必须填满可用高度；内部滚动，浏览器页面本身不产生多重纵向滚动条。

### 3.2 全局导航

- 桌面展开宽度为 `168px`，折叠宽度为 `64px`。
- 导航直接展示底面背景，不增加整栏底色、模糊层或独立卡片背景；工作区以白色工作面浮在其上。
- 展开态主导航项高度统一为 `42px`、圆角 `8px`，导航文字字重统一为 `600`；折叠态保留不小于 `44px` 的图标点击区域。
- 导航用户头像使用 `12px` 圆角且不显示边框，用户名使用标题黑。
- 导航选中项使用白色背景、标题黑和品牌色图标；未选中项使用中级黑。
- 主导航图标统一使用 `lucide-react`，尺寸 `18-20px`，文字 `14px`。

### 3.3 消息页面：三块布局

消息页面由三个视觉工作块组成：

1. 全局导航，宽 `168px`。
2. 会话列表，建议宽 `252-280px`，列表顶部不单独设置搜索或新建按钮。
3. 会话内容，自适应剩余宽度，包含固定会话头、消息流和固定输入区。

三块之间均露出 `8px` 底面背景。会话列表和消息流分别独立滚动，头部和输入区不得随内容滚动。新增链接等全局能力继续保留在全局导航原有位置，不在消息列表重复设置入口。

### 3.4 日历及常规页面：两块布局

日历、工作门户、业务系统、如意空间等常规页面按两块布局处理：

1. 全局导航。
2. 单一主工作面。

主工作面内部可以继续设置功能侧栏与内容区，但它们属于同一个工作面，使用分割线衔接，不再露出底面间隙。日历内部左栏承载搜索、小月历和日历列表，右侧承载日/周/月视图。

### 3.5 工作台页面

- 公文、PPT、参谋师等工作台仍作为一个主工作面呈现。
- 工作台内部允许缩略图栏、画布、属性栏等多栏结构，但外层必须遵守全局两块布局和独立滚动规则。
- 固定操作栏和属性栏不可覆盖画布内容；窄屏下优先收缩内部侧栏。

## 4. 文字与间距

- 字体顺序：`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`、系统无衬线字体。
- 页面标题 `20-24px / 600`；模块标题 `16-18px / 600`；正文 `14px / 400`；辅助文字 `12px / 400`。
- 字间距保持 `0`，不使用负字距。
- 基础间距单位为 `4px`，常用间距为 `8 / 12 / 16 / 24px`。
- 紧凑工具栏高度建议 `48-56px`；列表项最小可点击高度 `48px`。

## 5. 组件规则

- 命令按钮使用图标或“图标 + 文本”；熟悉的操作优先使用图标并提供 `title`。
- 主按钮使用品牌主色；次按钮使用白色或浅灰背景，不使用大面积渐变。
- 输入框圆角 `8px`，默认背景可用 `#F5F7FA`，聚焦时使用品牌色描边。
- 卡片仅用于可重复的信息实体、弹窗和独立工具，不把整个页面章节包装成悬浮卡片。
- 弹窗圆角不超过 `16px`，高风险操作必须二次确认。

## 6. 状态与反馈

- 选中态必须同时体现背景和文字/图标变化，不能只依赖颜色差异很小的边框。
- 加载、空状态、失败和完成状态都必须有明确文案与下一步操作。
- 删除、覆盖、重新生成等不可逆操作必须确认。
- 数据发生变化后提供可见反馈；禁止无提示静默完成。

## 7. 响应式与滚动

- Web Client 固定最小宽度 `1024px`：低于该宽度时不重排、不缩字号、不切换移动模式，由最外层 `web-client-viewport` 横向滚动。
- 全局导航始终处于正常文档流，不切换为覆盖式抽屉，不出现遮罩和移动端顶栏。
- 拖动条始终可用，不随视口宽度隐藏。
- 窄屏优先收缩侧栏、折叠工具，不通过缩小字号解决空间问题。
- 固定格式区域使用明确的宽度、网格或 `minmax`，避免内容变化引发布局跳动。
- 消息列表、会话内容、页面属性栏等区域独立滚动；默认隐藏滚动条，悬浮时显示。
- 禁止同一页面同时出现浏览器级和多个无意义的嵌套滚动条；横向滚动唯一来源是 `web-client-viewport`。
- `/admin`、`/download` 等独立页面不套用客户端视口，保留各自的响应式行为。

## 8. 实施检查清单

- 底面背景是否在页面四周和分栏之间可见。
- 消息页是否为导航、会话列表、会话内容三块结构。
- 其他客户端页面是否为导航和主工作面两块结构。
- 主工作面是否统一使用 `16px` 圆角和 `8px` 外间距。
- 配色是否使用语义变量与官方品牌色。
- 页面在 1440、1280、1024 宽度下是否无重叠、无横向溢出。
- 800、600 固定画布下 Web Client 是否保持 1024 布局，由最外层横向滚动，无重排、无缩字号、无移动模式切换。
- 头部、内容、底部操作区的滚动关系是否正确。
- 深色模式是否保持文字对比度和边界可辨识度。
- 完成后是否通过类型检查、生产构建和关键路由浏览器回归。

## 如意工作台统一规范（2026-10-14）

### 功能矩阵
| 功能 | 公文工作台 | PPT工作台 | 参谋师工作台 | 统一规则 |
|---|---|---|---|---|
| 返回与面包屑 | 如意空间/公文工作台 | 如意空间/PPT工作台 | 如意空间/参谋师工作台 | 同一顶部组件（h-14=56px） |
| 当前内容标题 | 公文标题 | PPT标题 | 汇报名称 | 面包屑下单行 font-semibold |
| 编辑工具栏 | 撤回/重做/复制 | 撤回/重做 | 无（不显示） | 仅真实支持的操作 |
| 右侧栏 | 320px（中屏300px） | 同左 | 同左 | 头部+滚动区+底部主操作 |
| 底部状态条 | 保存状态/AI提示/字数 | 保存状态/AI提示/页数 | 提交状态/AI提示/健康灯+周期 | 三栏 grid-cols-3 |
| 历史入口 | 我的公文 | 我的PPT | 所有汇报（顶栏右侧） | 保留现有位置 |

### 骨架规格
- 顶部 56px：32px 返回 icon + 面包屑（上级可点）/工作台名 + 当前标题 + 右侧业务操作
- 面包屑："如意空间"（可点，hover 变主题色+下划线） / 工作台名（灰色）
- 工具栏：px-4 py-2，同名操作同一样式；参谋师不显示无效工具
- 右侧栏：`w-80 max-w-[320px] max-lg:w-[300px]`，border-l，结构三段式
- 底部状态条：`grid grid-cols-3 px-4 py-2`，左状态/中AI提示/右业务摘要
- 响应式：编辑区与右栏独立滚动；1024px 起右栏收窄至 300px；设最小分辨率，不无限响应
