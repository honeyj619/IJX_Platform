
# 如意助手 - 公文辅助助手功能 PRD

## 1. 需求概述

### 1.1 产品背景
公文辅助助手是如意空间智能办公平台的核心功能模块之一，旨在帮助企业员工快速、高效地撰写各类正式公文文档，提升办公效率和文档质量。

### 1.2 功能定位
- 为企业员工提供公文模板选择和智能生成能力
- 支持多种公文类型和字数范围配置
- 提供简洁直观的操作界面

### 1.3 目标用户
- 企业内部需要撰写正式公文的员工
- 行政人员、管理人员、文秘等

---

## 2. 功能需求

### 2.1 核心功能

| 功能模块 | 功能描述 | 优先级 |
| :--- | :--- | :--- |
| 公文场景选择 | 支持选择公文类型（工作总结、会议讲话、通知、会议纪要等） | 高 |
| 字数范围选择 | 支持选择生成文档的字数范围 | 高 |
| 内容描述输入 | 支持输入公文内容描述，作为生成依据 | 高 |
| 公文生成 | 根据选择的场景、字数和描述，智能生成公文内容 | 高 |
| 参考文档上传 | 支持上传参考文档，辅助公文生成 | 中 |

### 2.2 公文场景列表

| 场景名称 | 说明 |
| :--- | :--- |
| 工作总结 | 用于汇报工作进展、成果和计划 |
| 会议讲话 | 用于准备会议发言稿 |
| 通知 | 用于发布正式通知公告 |
| 会议纪要 | 用于记录会议内容和决议 |
| 请示报告 | 用于向上级请示事项 |
| 函 | 用于单位之间的正式往来文书 |
| 批复 | 用于对下级请示的答复 |
| 决定 | 用于发布重要决策 |
| 公告 | 用于向社会公众发布重要信息 |
| 通报 | 用于表彰先进、批评错误、传达重要精神 |

### 2.3 字数范围选项

| 字数范围 | 适用场景 |
| :--- | :--- |
| 300-500字 | 简短通知、简短请示 |
| 500-800字 | 一般通知、简报 |
| 600-1200字 | 工作总结、会议纪要 |
| 1000-1500字 | 重要报告、详细请示 |
| 1500-2000字 | 长篇报告、复杂公文 |

## 3. 交互设计

### 3.1 界面布局

**工具选择区域**
- 展示4个工具按钮：公文、PPT、翻译、代码
- 点击"公文"工具后，展开公文助手输入面板

**公文助手输入面板**
- 顶部标题栏：显示"公文助手"标识
- 内容输入区：textarea文本框，提示"请输入您想要生成的公文内容描述..."
- 选项区：包含"场景选择"和"字数选择"两个下拉框
- 底部操作区：
  - 左侧："添加参考文档"按钮
  - 右侧："生成"按钮

### 3.2 交互流程

```
用户进入如意空间页面
    ↓
点击"公文"工具按钮
    ↓
展开公文助手面板
    ↓
输入公文内容描述（可选）
    ↓
选择公文场景（可选）
    ↓
选择字数范围（默认600-1200字）
    ↓
点击"生成"按钮
    ↓
跳转到文档编辑器页面，展示生成的公文内容
```

### 3.3 状态管理

| 状态 | 说明 |
| :--- | :--- |
| 初始状态 | 工具按钮未激活，显示默认输入框 |
| 公文工具激活 | 显示公文助手面板，场景和字数有默认值 |
| 生成中 | 显示加载状态 |
| 生成完成 | 跳转到文档编辑器页面 |

## 4. 界面设计

### 4.1 视觉规范

- **主色调**：主题色（theme）系，用于按钮、选中状态

## 5. 技术实现

### 5.1 前端技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS 3
- **图标**：Lucide React

### 5.2 组件结构

```
RuYiZone（如意空间主页面）
    ├── ToolBar（工具按钮区域）
    ├── GongwenPanel（公文助手面板）
    │   ├── TextArea（内容描述输入）
    │   ├── SceneSelector（场景选择下拉框）
    │   └── LengthSelector（字数选择下拉框）
    └── DocumentEditor（文档编辑器页面）
```

### 5.3 状态管理

- 使用 React useState 管理局部状态
- 公文场景默认值：空（请选择场景）
- 字数范围默认值：600-1200字

### 5.4 数据结构

```typescript
interface GongwenConfig {
  docType: string;        // 公文类型
  docTitle: string;       // 内容描述
  docLength: string;      // 字数范围
  docContent: string;     // 生成的内容
}
```

## 8. 附录

**输出**：
- 生成一篇符合格式要求的工作总结文档

## 9. 次级页面 - 文档编辑器功能

### 9.1 页面概述

文档编辑器是公文生成后的次级页面，提供文档预览、编辑、格式调整和AI辅助写作功能。

### 9.2 功能模块

| 功能模块 | 功能描述 | 优先级 |
| :--- | :--- | :--- |
| 文档预览 | 展示生成的公文内容 | 高 |
| 文本编辑 | 支持对生成内容进行手动编辑 | 高 |
| 格式工具栏 | 提供文本格式设置（粗体、斜体、下划线、对齐等） | 高 |
| AI写作工具 | 提供改写、润色、消色、灵感、校对、比对、AI助理等功能 | 高 |
| 公文模板选择 | 支持切换不同公文类型模板 | 中 |
| 大纲生成 | 根据文档内容生成大纲结构 | 中 |
| 结构风格参考 | 支持上传参考文档学习结构风格 | 中 |
| 内容参考 | 支持上传参考文档获取观点、案例和数据 | 中 |

### 9.3 界面布局

文档编辑器采用左右分栏布局：

**左侧 - 编辑区**
| 区域 | 内容 |
| :--- | :--- |
| 顶部工具栏 | 返回按钮、文档标题、保存状态、新建文档按钮、安全模式开关 |
| 编辑工具栏 | 撤销、重做、段落格式、字体选择、字号选择、粗体、斜体、下划线、列表、对齐方式、排版、清空内容 |
| 编辑区域 | 展示文档标题和生成内容，支持文本编辑 |
| 底部状态栏 | 提示信息和字数统计 |

**右侧 - 工作栏**
| 区域 | 内容 |
| :--- | :--- |
| 公文类型选择 | 法定公文/事务文书分类切换，模板按钮网格 |
| AI写作工具 | 竖条样式的工具按钮（改写、润色、消色、灵感、校对、比对、AI助理） |
| 文章信息 | 文章标题输入、篇幅选择、内容要求输入 |
| 大纲 | 可展开/折叠的大纲区域，支持生成大纲 |
| 结构风格参考 | 可展开/折叠区域，支持上传参考文稿 |
| 内容参考 | 可展开/折叠区域，支持上传参考文稿 |
| 底部操作 | 换一换、继续、排版、生成大纲、生成全文按钮 |

### 9.4 公文模板列表

| 分类 | 模板名称 |
| :--- | :--- |
| 法定公文 | 通报、情况报告 |
| 事务文书 | 会议纪要、方案、工作总结、工作报告、制度、整改报告、讲话稿、调研报告、述职报告、感谢信、表扬信、新闻稿、考察报告、日程议程、学习体会、请假条、其他 |

### 9.5 AI写作工具列表

| 工具名称 | 功能说明 |
| :--- | :--- |
| 改写 | 对当前内容进行重新组织和表达 |
| 润色 | 优化语言表达，提升文采 |
| 消色 | 去除文本中的颜色样式 |
| 灵感 | 提供创作灵感和建议 |
| 校对 | 检查文本中的语法和拼写错误 |
| 比对 | 与参考文档进行内容比对 |
| AI助理 | 提供智能写作辅助建议 |

### 9.6 交互流程

```
公文助手页面点击"生成"按钮
    ↓
跳转至文档编辑器页面
    ↓
展示生成的公文内容
    ↓
用户可进行以下操作：
    ├─ 直接编辑文本内容
    ├─ 使用格式工具栏调整样式
    ├─ 使用AI写作工具优化内容
    ├─ 切换公文模板类型
    ├─ 上传参考文档
    ├─ 生成大纲
    └─ 换一换（重新生成）
    ↓
点击"返回"按钮回到如意空间主页面
```

### 9.7 状态管理

| 状态 | 说明 |
| :--- | :--- |
| 初始状态 | 展示生成的文档内容，编辑工具栏默认状态 |
| 编辑状态 | 用户正在编辑文本内容，保存状态变为"未保存" |
| 格式状态 | 记录当前文本格式（粗体、斜体、下划线、对齐方式） |
| 展开状态 | 记录右侧工作栏各区域的展开/折叠状态 |

### 9.8 技术实现

**组件结构**
```
DocumentEditor（文档编辑器页面）
    ├── TopToolbar（顶部工具栏）
    ├── EditToolbar（编辑工具栏）
    ├── EditArea（编辑区域）
    ├── StatusBar（底部状态栏）
    └── Sidebar（右侧工作栏）
        ├── TemplateSelector（公文模板选择）
        ├── AiTools（AI写作工具）
        ├── DocInfo（文章信息）
        ├── OutlineSection（大纲区域）
        ├── StructureRefSection（结构风格参考）
        ├── ContentRefSection（内容参考）
        └── ActionButtons（操作按钮）
```

**数据结构**
```typescript
interface EditorState {
  content: string;           // 文档内容
  docTitle: string;          // 文档标题
  docType: string;           // 公文类型
  isBold: boolean;           // 是否加粗
  isItalic: boolean;         // 是否斜体
  isUnderline: boolean;      // 是否下划线
  textAlign: 'left' | 'center' | 'right';  // 对齐方式
  expandedSections: {        // 展开状态
    outline: boolean;
    structure: boolean;
    contentRef: boolean;
  };
  isSaved: boolean;          // 是否已保存
}
```
