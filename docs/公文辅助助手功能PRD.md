
# 如意助手 - 公文辅助助手功能 PRD

## 1. 需求概述

### 1.1 产品背景
公文辅助助手是如意空间智能办公平台的核心功能模块之一，旨在帮助企业员工快速、高效地撰写各类正式公文文档，提升办公效率和文档质量。

### 1.2 功能定位
- 为企业员工提供公文模板选择和智能生成能力
- 支持多种公文类型和字数范围配置
- 提供简洁直观的操作界面

### 1.3 目标用户
- 企业内部需要撰写正式公文的员工
- 行政人员、管理人员、文秘等

---

## 2. 功能需求

### 2.1 核心功能

| 功能模块 | 功能描述 | 优先级 |
| :--- | :--- | :--- |
| 公文场景选择 | 支持选择公文类型（工作总结、会议讲话、通知、会议纪要等） | 高 |
| 字数范围选择 | 支持选择生成文档的字数范围 | 高 |
| 内容描述输入 | 支持输入公文内容描述，作为生成依据 | 高 |
| 公文生成 | 根据选择的场景、字数和描述，智能生成公文内容 | 高 |
| 参考文档上传 | 支持上传参考文档，辅助公文生成 | 中 |

### 2.2 公文场景列表

| 场景名称 | 说明 |
| :--- | :--- |
| 工作总结 | 用于汇报工作进展、成果和计划 |
| 会议讲话 | 用于准备会议发言稿 |
| 通知 | 用于发布正式通知公告 |
| 会议纪要 | 用于记录会议内容和决议 |
| 请示报告 | 用于向上级请示事项 |
| 函 | 用于单位之间的正式往来文书 |
| 批复 | 用于对下级请示的答复 |
| 决定 | 用于发布重要决策 |
| 公告 | 用于向社会公众发布重要信息 |
| 通报 | 用于表彰先进、批评错误、传达重要精神 |

### 2.3 字数范围选项

| 字数范围 | 适用场景 |
| :--- | :--- |
| 300-500字 | 简短通知、简短请示 |
| 500-800字 | 一般通知、简报 |
| 600-1200字 | 工作总结、会议纪要 |
| 1000-1500字 | 重要报告、详细请示 |
| 1500-2000字 | 长篇报告、复杂公文 |

## 3. 交互设计

### 3.1 界面布局

**工具选择区域**
- 展示4个工具按钮：公文、PPT、翻译、代码
- 点击"公文"工具后，展开公文助手输入面板

**公文助手输入面板**
- 顶部标题栏：显示"公文助手"标识
- 内容输入区：textarea文本框，提示"请输入您想要生成的公文内容描述..."
- 选项区：包含"场景选择"和"字数选择"两个下拉框
- 底部操作区：
  - 左侧："添加参考文档"按钮
  - 右侧："生成"按钮

### 3.2 交互流程

```
用户进入如意空间页面
    ↓
点击"公文"工具按钮
    ↓
展开公文助手面板
    ↓
输入公文内容描述（可选）
    ↓
选择公文场景（可选）
    ↓
选择字数范围（默认600-1200字）
    ↓
点击"生成"按钮
    ↓
跳转到文档编辑器页面，展示生成的公文内容
```

### 3.3 状态管理

| 状态 | 说明 |
| :--- | :--- |
| 初始状态 | 工具按钮未激活，显示默认输入框 |
| 公文工具激活 | 显示公文助手面板，场景和字数有默认值 |
| 生成中 | 显示加载状态 |
| 生成完成 | 跳转到文档编辑器页面 |

## 4. 界面设计

### 4.1 视觉规范

- **移动端**：工具按钮横向排列，面板全屏展示

## 5. 技术实现

### 5.1 前端技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS 3
- **图标**：Lucide React

### 5.2 组件结构

```
RuYiZone（如意空间主页面）
    ├── ToolBar（工具按钮区域）
    ├── GongwenPanel（公文助手面板）
    │   ├── TextArea（内容描述输入）
    │   ├── SceneSelector（场景选择下拉框）
    │   └── LengthSelector（字数选择下拉框）
    └── DocumentEditor（文档编辑器页面）
```

### 5.3 状态管理

- 使用 React useState 管理局部状态
- 公文场景默认值：空（请选择场景）
- 字数范围默认值：600-1200字

### 5.4 数据结构

```typescript
interface GongwenConfig {
  docType: string;        // 公文类型
  docTitle: string;       // 内容描述
  docLength: string;      // 字数范围
  docContent: string;     // 生成的内容
}
```

## 8. 附录

### 8.1 界面原型说明

公文助手面板包含以下元素：
1. 标题栏：带如意图标和"公文助手"文字
2. 内容输入框：支持多行输入，灰色背景
3. 场景选择下拉框：包含10种公文类型
4. 字数选择下拉框：包含5个字数范围选项
5. 操作按钮：添加参考文档（左侧）、生成（右侧）

### 8.2 输入输出示例

**输入**：
- 场景：工作总结
- 字数：600-1200字
- 描述：本周完成了项目需求分析，召开了3次评审会议，编写了技术方案文档

**输出**：
- 生成一篇符合格式要求的工作总结文档
