# IJX Platform App 端设计规范

> 版本：2.0（已纳入官方设计规范）
> 适用范围：`/app` 移动端原型 与 移动端 H5 页面（同源 Vant 设计规范）
> 依据材料：官方设计规范截图（色彩 / 字体 / 按钮 / 导航 / 数据录入 / 空状态）、6 张 App 截图、IM 原型 `index.html`

## 1. 设计原则

- 移动端与 H5 统一使用 Vant 色彩与字体基线，保持轻量、克制、清晰；浅灰底（N1 `#F7F8FA`）+ 白色卡片。
- App 页面骨架为手机壳（`max-w-[430px]` 居中），截图原型实际宽度 360px，实现时按手机壳等比布局。
- 颜色与字号必须使用本文档登记的令牌；禁止在组件中散落近似色与近似字号。
- 底部 Tab 栏为 App 全局导航（首页/日程/工作台/消息/我的），所有 Tab 页均保留该栏。

## 4. 组件基线

### 4.1 导航栏（NavBar）

- 默认样式：左侧返回按钮 + 居中"页面标题"（标题使用正文 5 系，见 T6/T5）。
- 右侧文字：标题 + 右侧文字按钮；右侧插槽：标题 + 自定义插槽（图标/徽标）。
- 支持禁用状态（禁用态文字降级 N5）。
- 搜索框基础样式：圆角搜索条 + 占位提示文字，用于列表页顶部搜索入口。

### 4.2 按钮（Button）

| 类型 | Normal | Press | Disable |
| --- | --- | --- | --- |
| 主按钮 | 填充店铺主色（MR `#F53A71`），支持带 icon | 增加 20% 黑色蒙层（≈`#C42E5A`） | 灰化（禁用） |
| 次按钮 1 | 白底 + 边框（边框/文字色跟随店铺风格） | 加 8% 明度蒙版，蒙版色为边框色 | 加 70% 白色蒙层 |
| 次按钮 2 | 固定颜色样式，不跟随店铺风格 | 同左 | 同左 |

- 尺寸分级：主按（大）/ 中按 / 小按；通底按钮（通栏）；自定义按钮按业务场景定义大小样式。
- 危险/确认类操作仍需确认弹框（沿用项目约定）。

### 4.3 数据录入（Field）

- 基础样式：字段标题 + 输入框/选择框 + 输入内容提示。
- 提示规则：暗提示优先告知用户该表项的限制信息；提示需传达该表项的有效信息。
- 无字段名输入框的提示文案格式："请输入[字段名]，xx 个字以内"。
- 一行输入框标题与内容之间固定间距 12px；标题一行不超过 7 个字，超过折行展示，标题最多 12 个字。

### 4.4 空状态（Empty）

- 基础样式：图片垂直居中显示，距屏幕高度 30%；文案最多不超过两行，与图片间距 60px，文案居中显示；通用底色为白底。
- 图标场景分类：文本/任务、功能/应用类、优惠券、收藏、售货员类、接待、金额类、活动/规则、排行、通用类（卡片/消息）、更新类、资料/材料/订单、店铺、线索类。
- 空状态文案按页面语义配置，统一"我是标题 / 文案最多不超过两行"结构。

### 4.5 底部 Tab 栏

- 白底、顶部 1px 分割线（N3/N4）；图标 + 辅助文字（T0）；选中为 MR `#F53A71`，未选中 N5；未读红点角标支持。

### 4.6 页面骨架（截图提炼基线，待页面设计稿校准）

- **首页**：紫罗兰渐变头部 banner（截图近似 `#C492D1 → #D6BAE3`，实现以设计稿为准）；快捷服务宫格（图标 + 名称，白卡片网格）；通知公告列表（标题 + 文号 + 时间）；福利/精选双列商品卡片（缩略图 + 名称 + 价格）。
- **日程**：月历（当月日期 + 农历/节气标记，今日与有任务日期高亮 MR）；任务区（待处理/已处理分段，任务卡片含"提醒我"时间与创建人/参与人）。
- **工作台**：顶部搜索 + 编辑入口；应用宫格（推荐应用/综合服务分组），编辑模式可隐藏/排序应用。
- **我的**：顶部名片卡（头像/姓名/职位/部门/入职天数）；功能列表（图标 + 名称 + 右箭头，分组排列）；钱包区（余额 + 付款码）。
- **列表/表单**：复用 N 系分割线与弱阴影，不在移动端另造一套视觉。

## 5. IM 模块（消息 Tab）视觉基线

- IM 模块**只参考原型的功能与交互结构**（会话列表、聊天页、通讯录、搜索、历史、群聊、话题、转发/合并、投票/接龙、回执等），**样式统一使用本规范第 2-4 节的系统令牌**（玫红 MR `#F53A71`、中性色 N 系、字体 T 系、按钮/导航/表单/空状态组件基线），不使用原型自带的蓝色体系。
- 聊天页样式按系统落地：自己发送的气泡使用主色 MR `#F53A71`（浅色场景可用 N 系衬托），对方气泡白底 + N3/N4 边框；消息类型（图片/视频/语音/文件/名片/图文/表情/通话/投票/指令/合并）保持原型交互，但配色改用系统令牌。
- 会话列表行：头像 + 标题（含星标/置顶标）+ 时间 + 最后消息预览 + 免打扰/未读角标（角标用 MR/功能色）。
- IM 原型自带的「工作台」「我的」与 App 系统 Tab 重复，不建立独立 IM 版本，由 App 系统页承担；IM 功能页统一挂载在 App「消息」Tab（`/app/messages`）下。
- 若后续设计稿明确要求 IM 保留独立视觉，再调整并更新本节。

## 6. 维护规则

- 涉及 `/app` 与移动 H5 页面布局、配色、字体、Tab 栏或移动端组件的新增与调整，先读取本文件并遵循。
- 从截图/设计稿提炼出的稳定规则应同步更新本文件，避免多页各自定义视觉。
- 页面路径与平台规则见 `docs/APP_ROUTES.md`；页面开发阶段见 `docs/APP_DEVELOPMENT_PLAN.md`。
