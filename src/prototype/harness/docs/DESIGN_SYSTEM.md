# 员工端设计系统

本文件记录 i吉祥员工端移动原型的目标设计规则。权威视觉证据位于 `docs/references/spec-*`，页面组合证据位于 `docs/references/page-*`。当前 `src/` 中的旧红色、Font Awesome、通用卡片和固定数值不构成目标规范。

## 1. 设计方向与实现策略

- 产品类型：企业员工移动门户。
- 设计语言：浅色、高信息密度、航空品牌图片、黑色线稿图标加品牌粉色细节。
- 设计参数：低变化、低动效、高密度（3 / 2 / 8）。
- 员工端参考材料采用 Vant 色彩和组件规范，但当前工程没有安装 Vant。
- 默认策略是先将规范落为语义 Token 和 Vue 组件；是否安装 Vant 必须在具体实现任务中明确，不能在文档中假装已经使用。
- 当前参考图只定义浅色模式。深色模式在没有正式材料前标记为待补充，不自行生成。

| Token | 色值 | 用途 |

| `color.brand.primary` | `#F53A71` | 主要按钮、选中 Tab、重点数字、品牌强调 |

| `color.brand.blue-strong` | `#1761FF` | 辅助蓝色强调，不能替代员工端主色 |

## 3. 字体与字阶

参考图定义的是一倍图移动端字阶。Web 原型默认将数值映射为 CSS px；如果后续设计交付明确使用其他单位，再统一迁移。

| Token | 字号 | 行高 | 字重 | 使用场景 |
| --- | --- | --- | --- | --- |
| `type.t10` | 26px | 34px | 500 | 大标题 |
| `type.t9` | 20px | 28px | 500 | 标准标题一级 |
| `type.t8` | 18px | 24px | 500 | 标准标题二级 |
| `type.t7` | 17px | 23px | 400 | 主要正文、导航栏文字 |
| `type.t6` | 16px | 22px | 400 | 主要正文 |
| `type.t5` | 15px | 21px | 400 | 信息较多且需要多呈现的正文 |
| `type.t4` | 14px | 20px | 400 | 常规正文 |
| `type.t3` | 13px | 19px | 400 | 解释文字、协议条款 |
| `type.t2` | 12px | 16px | 400 | 次级解释文字 |
| `type.t1` | 10px | 14px | 500 | 标签和最小辅助文字 |

- 不再使用“字号必须为偶数”的规则。
- 中文字体优先使用系统无衬线栈；正式字体文件和授权待补充。未提供字体文件前，不声称已使用思源黑体。
- 同一级文字必须同时使用字号、行高和字重，不只复制字号。
- 底部导航、角标和标签不得小于 T1；重要正文不使用 T1/T2。
- 长标题优先换行或截断，不能单独缩小某个网格项的字号。

## 4. 画布、滚动和安全区

- 移动端页面宽度为 `100%`，桌面预览最大宽度暂保留 `480px`。
- 主视觉验收宽度为 360px，同时验证 375px 和 480px。
- 页面使用 `min-height: 100dvh`，不使用 `100vh` 作为唯一高度依据。
- 页面默认自然滚动，不在卡片内部创建独立滚动区。
- 顶部品牌背景是否延伸到安全区由页面基线决定：首页和“我的”允许品牌图延伸，普通内容页使用白色或 N1。
- 底部导航必须包含 `env(safe-area-inset-bottom)`；内容避让按“导航可见高度 + 安全区 + 内容间距”计算，不写死 70px。
- 浮动按钮相对应用画布定位，在桌面预览时不得漂移到 480px 画布之外。
- 弹层、键盘、浮动按钮和底部导航同时出现时必须验证遮挡和点击区域。

页面沟槽、卡片圆角和导航高度没有独立标注图时，以参考页面量取和视觉对比为准。候选数值必须写入当前任务并经过截图验收，不能仅因旧代码使用 12px 就升级为正式 Token。

## 5. 图标与图片

- 目标图标语言是黑色线稿轮廓，局部使用 `color.brand.primary` 点缀，线宽和视觉尺寸统一。
- 页面和底部导航优先使用设计提供的本地图标资源；同一网格不得混用实心 Font Awesome 和品牌线稿图标。
- Font Awesome 只属于当前旧实现。新页面不得默认继续使用。
- 不手绘临时 SVG 冒充正式品牌图标。缺少资产时使用明确标记的本地占位，并登记待替换。
- 品牌头图、Banner、商品和旅行图片必须保留比例、设置尺寸和 `object-fit`，并提供有意义的替代文本。
- 外部 URL 只能用于临时开发，评审和离线演示所需资源必须版本化或提供可解释降级。

## 6. Button

以 `spec-button.png` 为准。

### 主按钮

- Normal：品牌主色填充、白色文字、胶囊形。
- Press：在 Normal 上增加 20% 黑色蒙层，不能换成任意深红。
- Disable：在 Normal 上增加 70% 白色蒙层，同时禁用点击和键盘触发。
- 可带前置图标，图标与文字作为一个居中内容组。

### 次按钮 1

- Normal：白色填充、品牌主色描边和文字。
- Press：增加品牌描边色的 8% 透明蒙版。
- Disable：增加 70% 白色蒙层，并禁用交互。

### 次按钮 2

- 使用固定中性灰样式，不随业务主题色变化。
- Normal、Press、Disable 都必须有可区分状态。

### 尺寸与底部按钮

- 支持大按钮、中按钮和小按钮；同一尺寸的高度、内边距和圆角保持一致。
- 底部单操作使用全宽主按钮；双操作使用次按钮 + 主按钮，主按钮视觉权重大于次按钮。
- 点击目标建议不小于 44x44 CSS px；按钮文案单行显示。
- 任何可操作按钮必须有 `:active`、`:focus-visible` 和 `disabled` 状态。

## 7. NavBar 与搜索

以 `spec-navbar.png` 为准。

- 标准结构：左侧返回、居中标题、右侧可选文字或图标插槽。
- 支持浅色和深色背景；前景颜色随背景切换并保持对比。
- 禁用状态弱化左侧和右侧操作，但标题仍保持可读。
- 右侧没有操作时保留对称占位，避免标题视觉偏移。
- 搜索框包含默认态和有输入态；有输入态提供清除和取消。
- 搜索必须说明范围，并在无匹配时进入对应空状态。
- 一级页面可以使用品牌化头部，不强制套标准二级导航栏；二级页面优先使用本规范。

## 8. Empty

以 `spec-empty.png` 为准。

- 空状态由场景插图和文案组成，插图基准尺寸为 160px。
- 视觉中心位于可用内容区顶部约 25%-30%，不得复制固定 `padding-top` 适配所有页面。
- 文案最多两行，左右至少保留 60px，居中对齐。
- 根据场景选择网络、功能、接待、错误、搜索、商品、优惠券、金额、卡、资料、任务、收藏、活动、消息、店铺、客户、销售、排行、更新、线索、名片或核销等插图。
- 空状态取代列表内容，不与空白列表同时占位。
- 如果用户可以主动解决空状态，增加一个明确的下一步操作；纯结果为空时可以只显示说明。

## 9. Field

以 `spec-field.png` 为准。

- 单行录入采用“左侧标题 + 右侧内容/占位”的同一行结构，标题与内容固定间距为 12px。
- 暗提示优先说明限制或有效输入方式，不使用无信息量的“请输入”。
- 无独立字段名时，占位格式为“请输入[字段名称]，[限制]”，例如“请输入学员姓名，20个字以内”。
- 标题一行建议不超过 7 个中文字符；超出时允许折行，但标题总长度不超过 12 个中文字符。
- 必填、错误信息和选择箭头靠近对应字段；错误文字使用危险色并显示在字段内容下方。
- 录入和选择必须有默认、聚焦、已填、禁用和错误状态。
- 本规则是移动端行式 Field，不采用网页表单“标签一律置于输入框上方”的通用规则。

## 10. 底部导航

- 固定五栏：首页、日程、工作台、消息、我的。
- 图标在上、文字在下，五项等宽，整体包含底部安全区。
- 激活项使用品牌主色，未激活项使用 N6/N7；激活图标和文字同时变化。
- 图标必须来自同一品牌图标族，不能把圆点、方块或通用 Font Awesome 作为最终状态。
- 导航背景为白色，顶部可使用 N3 分隔线；阴影只在参考图需要时使用。
- 页面正文必须完整避让导航，不得依赖最后一个空白块碰巧撑开。

## 11. 页面组合规则

- 首页是高密度门户，不把所有模块统一包成白色卡片；品牌头图、横幅、列表、横向商品卡和双列推荐按参考图使用不同结构。
- 工作台以应用网格为主，分组标题和编辑操作形成清晰层级；不加入“最近使用/快捷入口”替代参考结构，除非有新需求。
- 日程页日历可以使用大块白色内容区；任务行使用轻分隔和充足行高，不强制每行独立圆角卡片。
- 我的页面使用航空品牌背景和分组菜单；高频服务与低频账户操作分离。
- 卡片只用于真实分组或层级。圆角、阴影和内边距在同一页面保持一致。

## 12. 状态与可访问性

- 可交互 `div` 必须改为语义按钮、链接或补足键盘、角色和可访问名称。
- 不设置 `user-scalable=no`，允许用户缩放。
- 正文和控件文字满足 WCAG AA 对比；图片上的文字需要遮罩或高对比背景。
- 图片提供 `alt`，纯装饰图使用空 `alt`。
- 使用 `:focus-visible`，不能只设计鼠标 hover。
- 动效只用于反馈和状态切换，并尊重 `prefers-reduced-motion`。
- 加载使用与最终布局匹配的骨架；错误就近说明；禁用态同时包含视觉和行为禁用。

## 13. 当前迁移差距

- 代码仍使用 `#D93030`、`#FF6B6B`、`#C4A35A` 等散落色值。
- 字阶、行高和字重尚未 Token 化。
- Font Awesome、DiceBear 和远程占位图片尚未替换。
- 旧页面大量使用通用白色圆角卡片，与版本化页面结构不一致。
- 底部导航没有把安全区纳入自身高度；页面仍使用固定 70px 避让。
- Button、NavBar、Empty、Field 尚未形成共享 Vue 组件。

上述内容只能在明确的迁移任务中改动产品代码；本文件本身不代表代码已完成迁移。
