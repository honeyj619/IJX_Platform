# 管理后台原型规范

## 文档状态

本文件记录管理后台的目标约束。当前仓库尚无管理后台路由、页面、组件或数据模型，因此未确认的布局尺寸、菜单结构、字段和权限均标记为“待补充”，不得将本文件描述为已经实现。

## 产品边界

- 管理后台服务平台运营管理员，用于配置门户内容、应用入口、用户组和功能展示范围。
- 员工端负责使用和办理，管理后台负责配置、预览、发布和验证，两者共享业务语义但使用独立信息架构。
- 管理端最低演示闭环：修改配置 → 校验 → 预览 → 保存 → 发布 → 切换员工视角 → 验证展示结果。
- 当前原型没有真实服务端和权限系统时，可以使用本地模拟状态，但必须清楚区分“草稿”“已发布”和“员工端生效结果”。

## 视觉边界

- 管理后台操作主色为 `#337AB7`，建议 Token 为 `color.admin.action.primary`。
- 员工端品牌主色 `color.brand.primary` 的变化不得覆盖管理后台操作色。
- 金色只作为品牌辅助色，不作为后台成功、警告、权限或发布状态色。
- 成功、警告、错误、禁用等后台状态使用独立语义 Token，具体色值待补充。
- 管理后台不使用员工端最大 480px 画布、固定底部五栏导航和移动端卡片门户骨架。

## 信息架构与页面壳层

- 管理后台采用桌面端信息架构；顶部栏、侧边栏、内容区宽度和断点待补充。
- 一级菜单按管理对象组织，不按员工端五个入口复制。
- 页面需要明确当前位置、页面标题和返回上级方式；是否使用面包屑待补充。
- 菜单结构、角色可见范围和默认首页需要在管理后台首次实现前确认。

## 页面类型

### 列表管理页

建议结构：页面标题 → 查询/筛选区 → 操作工具栏 → 数据表格 → 分页。

- 查询条件、表格字段和操作按钮应服务同一管理对象。
- 常用主要操作使用 `#337AB7`，如查询、新增、保存、确认；同一区域只保留一个视觉主操作。
- 行操作与批量操作分开；批量操作只有在选择记录后才可用。
- 表格需要加载、空数据、错误和无权限状态，不能只显示空白区域。
- 分页、排序、筛选是否保留由具体演示需求决定，确定后写入任务验收标准。

### 表格式表单页

V0.2 已确认管理后台表单采用表格形态：标签与字段按稳定列对齐，适合配置项密集的后台场景。

- 必填标识、字段说明、错误信息和单位应靠近对应字段。
- 同组字段使用一致标签宽度和对齐方式；具体列宽、行高和密度待补充。
- 保存前执行可见校验；失败时定位到字段并保留用户输入。
- 编辑页至少提供保存与取消；存在未保存修改时，离开页面需提示。
- 复杂字段可使用弹窗或抽屉辅助选择，但不能让主表单失去上下文。

### 配置、预览与发布页

- 配置编辑状态与员工端最终展示状态分离。
- 预览必须使用当前草稿；发布后员工视角才展示已发布版本。
- 保存草稿不等于发布，不显示误导性的“已生效”。
- 发布成功后展示明确结果，并提供进入员工视角验证的入口。
- 原型需要支持恢复初始演示数据或回到预设草稿，保证发布故事线可重复。

## 操作与反馈

- 主要操作：使用管理后台操作主色，文案采用“动词 + 对象”。
- 次要操作：使用普通按钮或文字操作，样式 Token 待补充。
- 危险操作：删除、停用、清空等必须二次确认；危险色 Token 待补充，不使用金色或主操作蓝色代替。
- 异步操作至少展示处理中、成功和失败反馈，避免重复提交。
- 删除、发布、启停等改变状态的操作，要同步更新表格、详情、统计和员工端预览中的相关状态。

## 权限与数据

- 当前角色只确认“平台运营管理员”，更细角色、数据范围和操作权限待补充。
- 无权限状态应明确说明不可查看还是不可操作，不能只隐藏所有内容造成空白页。
- 模拟数据不得包含真实敏感信息；共享业务对象应与员工端使用同一标识和状态语义。
- 若无后端，管理配置默认保存在当前浏览器本地，并明确不支持跨设备同步。

## 管理后台验证清单

- 页面标题、菜单位置和返回路径正确。
- 查询、筛选、重置、分页和排序按本轮需求工作。
- 表格包含加载、空、错误、无权限和正常数据状态。
- 新增或编辑包含校验、保存、取消和未保存离开提示。
- 主要、次要和危险操作视觉层级明确。
- 配置修改、预览、保存、发布和员工视角生效形成完整闭环。
- 同一业务对象在后台列表、详情和员工端展示中的状态一致。
- 浏览器刷新后演示状态符合本轮约定，并可重置演示数据。

## 待产品经理确认

- 管理后台菜单树、默认首页和管理对象清单。
- 目标桌面分辨率、最小宽度、顶部栏和侧边栏尺寸。
- 表格式表单的标签列宽、字段列宽、行高和页面密度。
- 表格默认列、固定列、操作列、分页规格和批量操作范围。
- 次要按钮、危险操作及成功/警告/错误状态色。
- 管理员角色、权限矩阵、数据范围和发布审批规则。
- 草稿、发布、撤回、回滚是否都需要进入原型闭环。
