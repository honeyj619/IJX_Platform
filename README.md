# IJX_Platform

企业内部智能助手平台，包含如意空间、管理后台等模块，提供公文辅助、PPT生成、翻译、代码助手等功能。

## 功能模块

### 工作门户
- **消息** — 即时通讯与消息通知
- **工作门户** — 企业工作台首页
- **日历** — 日程管理与会议安排
- **知识库** — 企业知识管理与搜索
- **业务系统** — 业务应用入口集成

### 智能助手
- **如意空间** — 智能助手入口，集成公文、PPT、翻译、代码等工具
- **公文助手** — 公文快速撰写与编辑（含公文工作台）
- **智能体广场** — 智能体浏览与管理
- **企业知识专家** — 企业知识问答助手
- **IT服务助手** — IT技术支持助手

### 办公协同
- **助理** — AI 助理对话
- **流程** — 工作流程管理
- **工作汇报** — 工作报告提交与管理
- **OKR** — 目标与关键成果管理

### 个人中心
- **个人信息** — 个人资料管理
- **系统设置** — 外观、通知、隐私、语言、存储等设置

### 管理后台
- **导航栏配置** — 自定义侧边栏导航与应用管理
- **用户组管理** — 按角色配置不同的导航权限

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
