# IJX_Platform

企业内部智能助手平台，包含如意空间、管理后台等模块，提供公文辅助、PPT生成、翻译、代码助手等功能。

## 功能模块

- **如意空间** — 智能助手入口，集成公文、PPT、翻译、代码等工具
- **管理后台** — 系统配置与导航栏管理
- **公文助手** — 公文快速撰写与编辑

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
